# SPECIFICATION: EPISTEMIC REFINEMENT LOOP (PHASE 5)
# Target: Autonomous Belief Revision based on tool outcomes.

## 1. PROBLEM STATEMENT
Currently, the agent uses fixed certainty scores for tool calls. 
When a tool returns an error or a 'REJECTED' decision, the agent does not 
automatically adjust its internal belief in that tool's reliability.

## 2. PROPOSED LOOP (The 'Refinement' Cycle)
1. **Capture**: Monitor all tool outputs (especially errors/rejections).
2. **Analyze**: Compare the 'expected outcome' with the 'actual outcome'.
3. **Update**: If a pattern of failure is detected, update the tool's 
   reliability score in `memory/config/tool_reliability.json`.
4. **Notify**: Update the agent's prompt/context to reflect the new confidence levels.
