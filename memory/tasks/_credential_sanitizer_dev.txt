
# TECHNICAL DESIGN: Credential-Sanitized Subprocess Wrapper

## Problem
The 'shell' and 'python' tools use `subprocess.run` or similar, which by default inherits `os.environ`. 
This exposes 'OPENROUTER_API_KEY', etc., to the child process.

## Proposed Solution: `env_scrub()`
A utility function to be used within `invoke_dynamic` or the `CHANNEL_EFFECTING` dispatch logic.

```python
import os

def get_sanitized_env():
    """
    Returns a copy of the current environment, excluding known sensitive keys.
    """
    sensitive_prefixes = ['API_KEY', 'TOKEN', 'SECRET', 'PASSWORD', 'AUTH', 'CRED']
    sanitized_env = os.environ.copy()
    
    keys_to_remove = []
    for key in sanitized_env.keys():
        if any(prefix in key.upper() for prefix in sensitive_prefixes):
            keys_to_remove.append(key)
            
    for key in keys_to_remove:
        del sanitized_env[key]
        
    return sanitized_env

# USAGE IN KERNEL (iter.py):
# result = subprocess.run(
#     cmd, 
#     env=get_sanitized_env(), 
#     capture_output=True, 
#     text=True
# )
```
