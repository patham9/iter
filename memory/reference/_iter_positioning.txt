ARCHITECTURE: CONCENTRIC RINGS
   - Core (immutable): agent loop, tool dispatch, memory interface — no monitoring
   - Inner ring (hard to modify): NAL truth revision (f,c) as belief backbone
   - Middle ring (modifiable with friction): LLM-based epistemic monitor (FM1-FM5 as instructions)
   - Outer ring (freely modifiable): regex gate as cheap fast first-pass filter
   - Refinement target (Jon Grove): friction should be evidentiary (counter-proof required),
     not just procedural (hard to edit)
